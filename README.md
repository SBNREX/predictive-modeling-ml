# Predictive Modeling Using Machine Learning

## Overview
A supervised machine learning project comparing Decision Tree and Random Forest classifiers.

## Dataset
Breast Cancer Wisconsin dataset from Scikit-learn.
- 569 samples
- 30 features
- Two classes: Malignant and Benign

## Algorithms
- Decision Tree Classifier
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

## Results

| Model | Accuracy | AUC |
|---|---:|---:|
| Decision Tree | 92.11% | 0.9163 |
| Random Forest | 95.61% | 0.9931 |

## Visualizations
- Confusion Matrices
- ROC Curve Comparison
- Accuracy Comparison

## Technologies
Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn

## Disclaimer
This is an educational project and is not intended for clinical diagnosis.
